# Orbit issue test builds

Test builds for fixes being verified with the Orbit community.

For everyday use, download the [latest Orbit Store and Orbit Zero release](https://github.com/saawant12/orbit-store-ps5/releases/latest).

## Download a test build

Open [Releases](https://github.com/saawant12/orbit-issues-test-builds/releases) and choose the build linked from your GitHub issue. Each release explains what it tests and provides packages for the supported operating systems and processors.

1. Quit Orbit Zero before installing or extracting a replacement.
2. Follow that test release's setup steps. If it includes an updated PS5 receiver, update both the desktop app and the receiver.
3. Check the package against the supplied SHA-256 checksums.
4. Report the result in the original issue, including your operating system and any error message.

See the [installation guide](https://github.com/saawant12/orbit-store-ps5/blob/main/guides/orbit-zero-installation.md) for Mac, Windows and Linux. Matching receiver source and licence information is linked from each test release.

Superseded testers are removed once their fixes ship in the regular release. Please use a current release rather than an old test-download link.
