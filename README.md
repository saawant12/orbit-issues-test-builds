# Orbit issue test builds

Public test builds for fixes being verified with the Orbit community. These builds are intended for testing the issues listed in each release. For regular downloads, visit [Orbit Store](https://github.com/saawant12/orbit-store-ps5/releases).

## Current test: Orbit Zero 1.0.2 (Test 1)

This build includes both the Vikingfile popup/navigation fix for [issue #33](https://github.com/saawant12/orbit-store-ps5/issues/33) and the computer download-folder setting for [issue #34](https://github.com/saawant12/orbit-store-ps5/issues/34).

[Open the test release](https://github.com/saawant12/orbit-issues-test-builds/releases/tag/orbit-zero-v1.0.2-test.1) and download the package matching your operating system and processor. Binary packages are attached under Assets.

Quit Orbit Zero before replacing it. Follow the [installation guide](https://github.com/saawant12/orbit-store-ps5/blob/main/guides/orbit-zero-installation.md) for your operating system. Mac ZIPs and portable Linux archives are also available in the release.

Please report your results in the original issue linked above, including your operating system, processor and any error message.

The packages include third-party notices and the Orbit Store 1.0.1 receiver. Its [corresponding source and licence bundle](https://github.com/saawant12/orbit-store-ps5/releases/download/v1.0.0/orbit-store-1.0.1-source-bundle.zip) remains available with the main Orbit Store release.
